# Introduction to Artificial Intelligence - Neps Academy

This repository provides all the necessary files and materials to support the course **Introduction to Artificial Intelligence** at Neps Academy.

## Repository Contents

- **lesson.py**  
  The Python script containing the core lessons and examples covered in the course.

- **titanic.csv**  
  The dataset used throughout the course for hands-on analysis and model building, focusing on the Titanic dataset.

- **titanic.ipynb**  
  A Jupyter Notebook that demonstrates the data processing, analysis, and machine learning workflow using the Titanic dataset. This notebook includes code examples, data visualization, model training, evaluation, and hyperparameter optimization.

## About the Course

This course introduces the fundamentals of Artificial Intelligence and Machine Learning. Through practical examples and hands-on exercises, you will learn how to:
- Process and analyze data
- Build predictive models using decision trees
- Optimize model performance with hyperparameter tuning techniques
- Work interactively with Jupyter Notebooks

All materials in this repository are intended to complement the lessons provided during the course at Neps Academy.
